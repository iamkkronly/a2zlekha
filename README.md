# Typography

**Handwritten font — `A2Z Photo Hand`:** Use the supplied custom font for its owner-drawn `A–Z`, `a–z`, and `0–9` glyphs. Use the local `.woff2` file for websites and the `.ttf` file for apps.

**Everything else:** Use rich, intentional typography—not a plain browser default. Choose a complementary readable font and create clear hierarchy with considered font pairing, scale, weight, spacing, line-height, and contrast.

Do not replace or modify the supplied handwritten font files.
